# 256 Foundation Brand Assets

Official logo kit for the 256 Foundation, copied into the brain from the
256F Shared Drive (`Content & Marketing/Branding Package/MacyBrandingKit/256 Foundation New Logos`)
on 2026-10-07. Filenames were normalized to kebab-case; nothing else was altered.

## Inventory (11 variants × PNG + EPS)

| Variant | Files | Use for |
|---|---|---|
| Horizontal | `256-logos-horizontal-1/2` | Headers, banners, wide layouts |
| Vertical | `256-logos-vertical-1/2` | Stacked/narrow layouts |
| Icon Circle | `256-logos-icon-circle` | Avatars, favicons, app icons |
| Icon Square | `256-logos-icon-square` | Icons where square crop is required |
| Secondary | `256-logos-secondary-1/.../5` | Alternate lockups per the brand guide |

- **PNG** — raster, use for web/screens/docs.
- **EPS** — vector, use for print and scaling.

## Rules

- These are the canonical assets for anything the team ships (sites, decks, demos).
- **Do not modify, recolor, stretch, or redraw.** If the official kit is updated
  on the shared drive, replace this folder wholesale so the repo never forks the brand.
- Link to files here rather than pasting copies into other repos.
